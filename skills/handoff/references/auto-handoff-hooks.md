# Auto-Handoff Hooks

### Auto-Trigger (context-size detection)

`hooks/auto-handoff-stop.py` is a Claude Code **Stop hook**. After each turn it reads the transcript's last `usage` block (input + cache tokens); once context reaches the threshold it blocks the stop and instructs the agent to run this skill end to end (doc → `herdr-handoff.sh --kind claude --mode <code|plan>`). One-shot per session (flag file `/tmp/claude-auto-handoff-<session_id>.flag`).

- Threshold: `CLAUDE_AUTO_HANDOFF_THRESHOLD` (default `320000`), hard cap `CLAUDE_AUTO_HANDOFF_HARD_CAP` (default `480000`), min work delta `CLAUDE_AUTO_HANDOFF_MIN_DELTA` (default `100000`). Disable: `CLAUDE_AUTO_HANDOFF=0`.
- **It waits for a safe point.** Past the threshold the hook stays silent while this session has background work running or the session's working tree has uncommitted changes to tracked files; it looks again after the next turn. Running work is found by replaying the transcript in order, per task id: a launch (an agent, a background command) or a `SendMessage` resume sets it running, a task notification or kill sets it done, and whatever is running at the end counts. So an agent that reported once and was then resumed holds the handoff back again. Past the hard cap, `CLAUDE_AUTO_HANDOFF_HARD_CAP` (default 1.5 x the threshold), it fires regardless. When it fires, the instruction carries `--running N` with its own count, and with N>0 it writes a `.draining` marker so later reminders tell this tab to relay results instead of "stop", and one more tells it when the last agent has reported. A newer owner instruction wins over the drain notice. Context is the last `message` iteration of the newest usage record (an advisor call adds an iteration that the top-level totals would double-count). A guard blocks once when this session got a drain or mid-turn notice, no handoff ran, and the last reply claims one is happening; a `herdr-handoff.sh` banner in the transcript (a manual run) counts as a handoff. Limits: only the session's own directory is checked for uncommitted changes, not other worktrees it edits; untracked files do not count; transcript text that merely quotes a launch line counts as a launch, which only delays the handoff until the hard cap; so does a background task that ends without a task notification (for example one that dies with a restarted session). Subagents the transcript cannot show (AGY `manage_subagents`) are covered only by your own count in step 3a. Tests: `tests/test_auto_handoff_stop.py`, `tests/test_herdr_handoff.py`.
- Install on a new machine:
  ```bash
  ln -s ~/.claude/skills/handoff/hooks/auto-handoff-stop.py ~/.claude/hooks/auto-handoff-stop.py
  ```
  then add to `~/.claude/settings.json` under `hooks.Stop[].hooks`:
  ```json
  { "type": "command", "command": "python3 ~/.claude/hooks/auto-handoff-stop.py", "timeout": 10 }
  ```
- **Mid-turn check (optional).** A Stop hook only runs when a turn ends, and one long turn can add hundreds of thousands of tokens. `hooks/auto-handoff-midturn.py` is a **PreToolUse hook** that reads the newest main-session usage record before each tool call and, once per level (`CLAUDE_AUTO_HANDOFF_MIDTURN_LEVELS`, default `320000,400000,480000,560000`), adds a note asking the agent to finish the unit of work and end the turn so the Stop hook can hand off. It never denies a tool call and ignores subagents. **Notes are off unless `CLAUDE_AUTO_HANDOFF_NOTICES=1`** (log only otherwise). Install like the Stop hook, under `hooks.PreToolUse[].hooks`. Tests: `tests/test_auto_handoff_midturn.py`.
- **PreToolUse Bash Guard (`hooks/handoff-bash-guard.py`).** In Claude Code `auto` mode, piping `herdr-handoff.sh` into a read-only command (`| tail -15`) triggers `serverHeldShellAllow`, revoking the `settings.json` allow rule and sending the command to the server-side auto-mode classifier (which denies agent-spawning scripts with no explanation). `handoff-bash-guard.py` intercepts any piped, redirected (`2>&1`), chained (`&&`), tilde-prefixed (`~/.claude/...`), `--no-yolo`, or missing-file invocation of `herdr-handoff.sh` and immediately returns a `PreToolUse` `deny` with an explicit `permissionDecisionReason` and the exact standalone command to run. Clean standalone calls exit `0` with empty stdout (never rewriting `updatedInput`, which would void auto-mode verdicts). Tests: `tests/test_handoff_bash_guard.py`.

### AGY Native Auto-Handoff (`~/.gemini/config/hooks.json`)

In Google Antigravity (`agy`), auto-handoff hooks operate natively via AGY's JSON hook schema:
- **`Stop` Hook (`hooks/auto-handoff-stop.py`)**: Fires when `terminationReason in ("NO_TOOL_CALL", "MAX_TOKEN_BUDGET_EXCEEDED", "MAX_INVOCATIONS", "model_stop")`. Inspects session token growth from `transcript.jsonl` / `transcript_full.jsonl` or `conversations/<id>.db*`. Default threshold is `380000` tokens (`AGY_AUTO_HANDOFF_THRESHOLD`), hard cap `520000` tokens (`AGY_AUTO_HANDOFF_HARD_CAP`), with a required `min_work_delta` of `100000` tokens (`AGY_AUTO_HANDOFF_MIN_DELTA`). When below `min_work_delta` (and under hard cap / not `MAX_TOKEN_BUDGET_EXCEEDED`), waits quietly (`delta-wait` log, no contradictory drain notice or drain marker) to let the session accumulate sufficient work. Notices in AGY default ON (`AGY_AUTO_HANDOFF_NOTICES != "0"`), whereas in Claude they default OFF (`CLAUDE_AUTO_HANDOFF_NOTICES == "1"`, log only). When exceeding threshold at a safe point (or regardless at hard cap / `MAX_TOKEN_BUDGET_EXCEEDED`), returns `{"decision": "continue", "reason": "AUTO-HANDOFF: ... run herdr-handoff.sh <doc-path> --kind agy --mode <code|plan> ..."}`.
- **`PreInvocation` Hook (`hooks/auto-handoff-midturn.py`)**: Mid-turn hook that monitors cumulative token consumption before LLM calls at levels `[300000, 380000, 460000, 520000]`. Injects advisory notices instructing the agent to wrap up the current logical unit of work.
- **PreToolUse Bloat Guard (`hooks/agy-read-bloat-guard.py`)**: Intercepts `read_file` / `view_file`. Denies reading raw `transcript*.jsonl` files (>24KB) without narrow line boundaries (<=80 lines) to prevent dumping 12K-30K tokens per read. Automatically downscales oversized raster images (>1024px) via macOS `sips` with disk cache to prevent burning context on screenshots.
- **Turn-1 Discipline & Rule 6**: Handoff documents must stay within 4 KB - 6 KB, avoid raw `transcript.jsonl` references (summarize in `## Late results`), and follow the Turn-1 cold-start budget (<=15K tokens: run Section 0 claim + 4.1 immediate action only; no speculative bulk reads).
